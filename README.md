# Bitrix Tools

Ускорьте разработку на 1С-Битрикс в VS Code. Расширение добавляет умную навигацию по компонентам и упрощает рутинные задачи разработчика.

## 🚀 Возможности

- **Быстрая навигация**: переход к шаблонам компонентов прямо из кода (`IncludeComponent`).
- **Умный поиск шаблонов**: автоматическое определение путей в проекте.
- **Гибкая настройка**: поддержка работы с несколькими шаблонами сайтов.

## ⚙️ Настройки (Settings)

Расширение добавляет следующие параметры в настройки VS Code (`settings.json`):

* `bitrixTools.siteTemplate` — имя папки шаблона сайта.
* Ищет в `local/templates/` или `bitrix/templates/`.
* Используется для разрешения путей компонентов.
* Оставьте пустым для ручного выбора из списка.

## 📋 Требования

* **VS Code**: версия `1.90.0` или выше.
* **Язык**: установленная поддержка PHP.

## 🗺️ Планы на будущее (Roadmap)

В следующих версиях планируется добавить:
* **Авто-развертывание**: автоматическое скачивание `restore.php` и файлов для быстрой установки Битрикса.
* **Генерация кода**: готовые шаблоны компонентов для быстрого создания новых кастомных блоков.
* **Сниппеты**: набор полезных сниппетов для часто используемых функций и конструкций API Битрикса.
* **Умное автодополнение**: подсказки при вводе компонентов (например, для `bitrix:catalog` автоматически предложатся доступные шаблоны).
* **Интеграция с докой**: быстрые ссылки на официальную документацию прямо из кода компонента.
